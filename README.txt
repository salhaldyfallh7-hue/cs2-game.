العمليات الخاصة: كتيبة الصاعقة
نسخة المتصفح الجاهزة لـ GitHub Pages وNetlify

تشغيل اللعبة
- افتح index.html عبر خادم ويب أو استضف المجلد كما هو.
- اللعبة صفحة ثابتة ولا تحتاج إلى بناء أو تثبيت حزم.
- تحتاج اللعبة إلى اتصال بالإنترنت لتحميل محرك الرسوم Three.js من CDN.

النشر على GitHub Pages
1. ارفع ملفات هذا المجلد إلى جذر المستودع.
2. افتح Settings ثم Pages في المستودع.
3. اختر النشر من الفرع الرئيسي ومن مجلد /(root)، ثم احفظ.
4. افتح الرابط الذي يعرضه GitHub Pages.

النشر على Netlify
- اسحب المجلد إلى Netlify Drop، أو اربط المستودع الذي يحتوي على هذه الملفات.
- ملف netlify.toml يحدد جذر النشر، ولا يلزم أمر build.

محتويات المجلد
- index.html: اللعبة كاملة في صفحة واحدة.
- netlify.toml: إعداد نشر Netlify.

المهمات والتقدم
- 12 عملية متنوعة، تتضمن الاستطلاع والاستعادة والتعطيل والإنقاذ والتثبيت والصمود.
- أربعة مستويات صعوبة، وتزداد أعداد الخصوم وقوتهم مع تقدم العمليات.
- بيوت ومخابئ وطرق وحواجز وصناديق وبراميل يمكن الاحتماء بها أو الالتفاف حولها.
- تحفظ الرتب والرصيد والتقدم داخل المتصفح. الحفظ خاص بالمتصفح والجهاز، ولا ينتقل تلقائياً بين الروابط أو الأجهزة.

التحكم
- W A S D للحركة، Shift للركض، Ctrl للانحناء، Space للقفز.
- الفأرة للتصويب، زرها الأيسر للإطلاق، والزر الأيمن للتصويب الدقيق.
- R لإعادة التلقيم، Q لقدرة العميل، E للتفاعل، وEsc للإيقاف.
